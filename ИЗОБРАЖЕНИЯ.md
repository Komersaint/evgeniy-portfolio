# Изображения: промпты и способ генерации

Все ассеты сайта сгенерированы нативной моделью **MiniMax H3 Image** в этой же сессии
через коннектор `connector__matrix__generate_image` (CLI `mcode-tools`).

## Как это сделано

```bash
# 1. Запрос подготовлен отдельным JSON-файлом (см. tools/images/requests/)
mcode-tools connector call connector__matrix__generate_image --args-file tools/images/requests/hermes.json

# 2. Ответ содержит node_id и file_name — чеки сохранены в tools/images/receipts/

# 3. Файл скачивается по короткоживущей ссылке
mcode-tools get_asset_url <node_id>
```

Параметры всех генераций: `area: 4K`, `output_format: jpeg`, `n: 1`.
Соотношения сторон — по назначению: `16:9` для горизонтальных карточек, `4:3` для вертикальных.

**Оригиналы (4K)** лежат в `public/images/generated/` — не трогайте их, это полноразмерные исходники.
В вёрстке они не используются, но попадают в папку `out/` при сборке (+23 МБ к размеру деплоя).
Если это не нужно — перенесите папку из `public/` в корень проекта перед деплоем: ссылок на неё
в коде нет.

**Веб-версии** лежат в `public/images/` — те же картинки, уменьшенные длинной стороной до 1600 px
и пережатые (JPEG, качество 76). Именно они подключены в вёрстке: от 175 до 380 КБ вместо 2–4 МБ.
Сайт грузит их лениво (`loading="lazy"`), кроме портрета на главной.

Пересоздать веб-версии из оригиналов:

```bash
cd public/images
for f in generated/*.jpg; do
  sips -Z 1600 -s format jpeg -s formatOptions 76 "$f" --out "$(basename "$f")"
done
```

## Единый художественный стиль

Премиальная предметная editorial-фотография: тёплая бумага, натуральное стекло, керамика, медь,
матовый металл, мягкий боковой свет, много воздуха. Палитра: молочный, кремовый, графитовый,
терракотовый.

Внутри картинок нет надписей, псевдо-UI, роботов, неона и «технологических» деталей — по требованию
к дизайну. Композиции под конкретные места в карточках, а не «для красоты».

## Портрет

Портрет — **реальное фото Евгения**, обработанное тем же H3 Image: уличный фон заменён на
студийный кремовый фон в тоне «новой бумаги», свет приведён к мягкому студийному, кадр
перекомпонован в «плечи + воздух над головой». Лицо не перерисовывалось — модель работала как
редактор: меняла только фон и свет.

- Оригинал: `public/images/generated/portrait-paper.jpg` (4096×4096, 4K)
- Веб-версия: `public/images/portrait.jpg` (1200×1200, JPEG 82, ~183 КБ)
- Промпт: `tools/images/requests/portrait.json`, чек: `tools/images/receipts/_receipt-portrait-v2.json`

Первый вариант (слишком крупный план лица) отброшен. Отдельная попытка вырезать фон утилитой
`remove_image_background` фон не отделила — понадобился именно редактирующий путь.

Замена портрета на новый: положить свой файл в `public/images/portrait.jpg` (квадрат,
1000–1200 px). Если фото вертикальное, пропорции подстроит `object-fit: cover` — см.
`.hero__portrait` в `src/app/bento.css` и `.about__portrait` в `src/app/layout.css`.
